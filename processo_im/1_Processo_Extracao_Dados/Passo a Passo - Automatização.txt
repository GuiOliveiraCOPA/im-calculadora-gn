PASSO A PASSO - AUTOMATIZAÇÃO GN

OBJETIVO
Esta automação atualiza as tarifas de GN a partir dos sites oficiais das distribuidoras/órgãos reguladores.
Ela gera uma planilha central única e também planilhas individuais por estado para conferência.

COMO ATUALIZAR
1. Abra a pasta: Downloads\Atualizacao_GN\Comece_aqui.
2. Feche a planilha Planilha_GN_Atualizada.xlsx se ela estiver aberta no Excel.
3. Dê dois cliques em AtualizarDados.bat.
4. Quando a janela pedir, digite o nome do responsável pela atualização. Se quiser usar o usuário do Windows, apenas pressione Enter.
5. O botão usará primeiro a pasta Comece_aqui\AmbientePython, que já contém o Python e as bibliotecas necessárias.
6. Aguarde a janela terminar. Pode levar alguns minutos.
7. Se aparecer "Concluido com sucesso", confira a planilha final em:
   Downloads\Atualizacao_GN\Comece_aqui\Planilha_Final\Planilha_GN_Atualizada.xlsx
8. Ao abrir a planilha, leia primeiro a aba Aviso antes de alterar qualquer dado.

ARQUIVO PRINCIPAL PARA USO NORMAL
- AtualizarDados.bat
  É o único botão de atualização. Execute apenas este arquivo para atualizar os dados.

ARQUIVO FINAL GERADO
- Planilha_Final\Planilha_GN_Atualizada.xlsx
  É a planilha central atualizada. O nome é sempre o mesmo; a automação sobrescreve os dados dentro dela.
  Esta planilha está vinculada a outra base de dados. Altere somente se tiver certeza do impacto.

PASTAS DA AUTOMAÇÃO
- AmbientePython
  Guarda o Python portátil e as bibliotecas usadas pela automação.
  Esta pasta permite rodar em outra máquina mesmo sem Python instalado.
  Não apague, renomeie ou edite esta pasta. Se a pasta estiver em nuvem, aguarde a sincronização completa antes de executar.

- Fonte_Dados
  Guarda os códigos internos da automação, incluindo os extratores por estado.
  Não abra, edite, renomeie ou apague arquivos desta pasta, a menos que esteja fazendo manutenção técnica.

- Execucoes_CMD
  Guarda os logs de cada execução do botão AtualizarDados.bat.
  Se der erro, envie o arquivo de log mais recente desta pasta para análise.
  Pode apagar logs antigos se quiser limpar a pasta, mas não apague a pasta Execucoes_CMD.

- Planilha_Final
  Guarda a planilha central final: Planilha_GN_Atualizada.xlsx.
  É aqui que a equipe deve buscar o resultado principal.
  Não deixe a planilha aberta enquanto roda a automação, porque isso impede a atualização.

- Fonte_Dados\PlanilhasUf
  Guarda as planilhas individuais por estado/site.
  Elas servem para conferência dos dados extraídos separadamente.
  Pode apagar arquivos antigos desta pasta antes de testar, mas não apague a pasta PlanilhasUf.

- PassadoTarifas
  Guarda o histórico das tarifas identificadas pela automação.
  A automação só salva uma nova planilha nesta pasta quando encontra uma versão de dados que ainda não existe no histórico daquele estado/site.
  Se a mesma tarifa já foi arquivada antes, o código central não cria outra cópia, mesmo que a atualização seja executada novamente.
  O arquivo controle_historico_tarifas.json registra a assinatura técnica usada para saber se a tarifa é nova ou repetida.
  Não apague esta pasta nem o arquivo de controle, a menos que queira reiniciar o histórico.

O QUE PODE MEXER
- Pode abrir e consultar Planilha_GN_Atualizada.xlsx.
- Pode copiar Planilha_GN_Atualizada.xlsx para outro local, se precisar analisar sem alterar o arquivo oficial.
- Pode apagar logs antigos dentro de Execucoes_CMD.
- Pode apagar planilhas antigas dentro de Fonte_Dados\PlanilhasUf para fazer um teste limpo.
- Pode mover a pasta Atualizacao_GN inteira para outro local do computador.

O QUE NÃO DEVE MEXER
- Não renomeie AtualizarDados.bat.
- Não renomeie as pastas Comece_aqui, AmbientePython, Fonte_Dados, Execucoes_CMD, Planilha_Final e PassadoTarifas.
- Não apague nem mova a pasta AmbientePython.
- Não renomeie, edite ou apague os arquivos tabela_*.py dentro da pasta Fonte_Dados.
- Não edite o codigo_central.py nem o requirements.txt dentro da pasta Fonte_Dados sem orientação técnica.
- Não rode os arquivos Python individualmente; use apenas AtualizarDados.bat.
- Não execute a automação com Planilha_GN_Atualizada.xlsx aberta no Excel.

REGISTRO DE QUEM ATUALIZOU
- Cada execução gera um log dentro de Comece_aqui\Execucoes_CMD.
- O nome do log segue este padrão: Execucao_001_yyyy-mm-dd_usuario.log.
- O número da execução aumenta conforme novos logs do mesmo dia são criados.
- Ao executar AtualizarDados.bat, a janela pergunta o nome do responsável.
- Se a pessoa apenas pressionar Enter, será usado o usuário Windows automaticamente.
- Dentro do log ficam registrados o responsável informado, o usuário Windows, o computador, a data/hora de início, a data/hora de término e o status da execução.
- A planilha Planilha_GN_Atualizada.xlsx também mostra na aba Aviso quem foi o último responsável pela atualização, o computador utilizado e o horário de início.
- A aba controle também guarda esses metadados para conferência técnica.

DEPENDÊNCIAS DO PYTHON
- A automação agora vem com a pasta Comece_aqui\AmbientePython.
- Essa pasta já contém o Python portátil e as bibliotecas necessárias, como openpyxl, pandas, requests, pdfplumber, PyMuPDF e selenium.
- Em uma máquina nova, a pessoa não precisa instalar Visual Studio, VS Code, Python ou bibliotecas manualmente, desde que copie/sincronize a pasta Atualizacao_GN inteira.
- Se a pasta AmbientePython não estiver presente, o botão ainda tentará usar o Python instalado na máquina como plano B.
- Se aparecer erro dizendo que o AmbientePython está incompleto, aguarde a sincronização da nuvem terminar e tente novamente.

SE DER ERRO
1. Não mexa nos códigos.
2. Abra a pasta: Downloads\Atualizacao_GN\Comece_aqui\Execucoes_CMD.
3. Pegue o arquivo .log mais recente.
4. Envie esse log para quem faz a manutenção da automação.

O MAIS IMPORTANTE
- Para atualizar: clique em Comece_aqui\AtualizarDados.bat.
- Para pegar o resultado: abra Comece_aqui\Planilha_Final\Planilha_GN_Atualizada.xlsx.
- Para investigar erro: use o log mais recente em Comece_aqui\Execucoes_CMD.
- Para consultar versões antigas de tarifas: use Comece_aqui\PassadoTarifas.
- Para preservar a automação: não altere as pastas AmbientePython e Fonte_Dados.
